# 🛡️ 实时诊断与算法风控模块文档 (readme_liveanalyzer.md)

本模块为实时个股分析器（`LiveAnalyzer`）提供了工业级的量化风控决策引擎及套牢恢复助手。以下为该模块的核心功能设计、算法公式、UI 交互及代码结构的详尽技术说明。

---

## 一、 模块核心功能概述

当用户在左侧参数配置区输入了**持仓成本价 (Cost Basis)** 后，风控诊断引擎将自动激活，并输出以下维度的动态诊断建议：

1. **初始硬止损 (Initial Stop Loss)**：防范入场后的突发暴跌风险（默认亏损达 **-10%** 触发无条件离场）。
2. **移动止盈 (Trailing Stop)**：跟踪买入后的最高价，当股价自最高点回撤达到设定门槛（默认 **15%**）时，触发止盈，锁定大部分利润。
3. **保本锁保护 (Breakeven Protection)**：当浮盈一度达到设定门槛（默认 **30%**）后自动开启。开启后，若股价跌回保本保护线（成本价 $\times 1.05$），触发强制保本离场，对冲佣金摩擦，确保绝对不亏本金。
4. **MACD 辅助减仓 (MACD Dead-Cross Exit)**：当浮盈超过 15% 且日线 MACD 刚出现或处于“死叉”状态时，触发 **50% 分批减仓** 信号，落袋为安。
5. **智能参数推荐 (Smart Defaults)**：分析股票自身历史日均波幅百分比 (Average ATR %)，智能划分波动属性（低、中、高波动股），并提供“一键套用”的黄金推荐参数。
6. **套牢盘解套小助手 (Trapped Recovery Assistant)**：当账面亏损达到 **-15% 及以上** 时触发。结合当前个股所处的威科夫（Wyckoff）或经典技术分析阶段，输出工业级的解套方案与滚动做T价位参考。

## 二、 量化风控核心算法与数学公式

### 1. 智能入场点估算 (Entry Index Estimation)
由于工具只需用户输入“成本价”而无须填入复杂的成交时间，算法会在历史 K 线（通常为 60-90 天）中逆向推演最合理的买入时点 $entryIdx$：
* **有交叉点**：若历史上存在多根 K 线的高低价范围覆盖了成本价 $Cost$，取**最后一次（最近一次）**交叉点作为入场索引 $entryIdx$。这代表当前持仓趋势的真正起点。
* **极低成本**：若成本价低于历史所有的最低价，说明买入极早，设定 $entryIdx = 0$。
* **高位套牢**：若成本价高于历史所有最高价，寻找收盘价与成本价差值绝对值最小的 K 线索引作为 $entryIdx$。

### 2. 真实入场后最高价计算 (Post-Entry Peak Price)
为了剔除用户买入**之前**发生的历史最高价干扰，系统截取入场点以后的价格序列进行计算：
$$\text{Peak Price} = \max\left(\text{High}[i] \mid i \ge entryIdx\right)$$

### 3. 风控参考价格指标
* **初始硬止损价 (Stop Loss Price)**:
  $$\text{Stop Loss Price} = \text{Cost Basis} \times 0.90$$
* **移动止盈触发价 (Trailing Stop Price)**:
  $$\text{Trailing Stop Price} = \text{Peak Price} \times \left(1 - \frac{\text{maxDrawdownPct}}{100}\right)$$
  *(注：移动止盈触发时无条件离场，不再受浮盈必须大于 0% 的条件限制。)*
* **保本激活目标价 (Breakeven Trigger Price)**:
  $$\text{Breakeven Trigger Price} = \text{Cost Basis} \times \left(1 + \frac{\text{breakevenTriggerPct}}{100}\right)$$
* **保本平仓保护线 (Breakeven Exit Price)**:
  $$\text{Breakeven Exit Price} = \text{Cost Basis} \times 1.05$$

### 4. 智能个股波动率分类 (Smart Volatility Recommender)
遍历历史 K 线计算**日均波幅百分比 (Average ATR %)**：
$$\text{Average ATR \%} = \frac{1}{M}\sum_{i=1}^{M}\left(\frac{\text{ATR}_i}{\text{Close}_i}\times 100\right)$$
* **低波动股 (Low Volatility)** ($Average\ ATR\ \% < 1.8\%$): 推荐 `移动止盈 10%` / `保本门槛 20%`
* **中波动股 (Moderate Volatility)** ($1.8\% \le Average\ ATR\ \% \le 3.5\%$): 推荐 `移动止盈 15%` / `保本门槛 30%`
* **高波动股 (High Volatility)** ($Average\ ATR\ \% > 3.5\%$): 推荐 `移动止盈 20%` / `保本门槛 40%`

### 5. 工业级风控执行规则 (Risk Execution Hierarchy)
* **柔性套牢防守机制**：平仓信号（`EXIT_ALL`，由初始止损、移动止盈或自适应保本锁触发）在一般状态下会直接建议离场。但是，当个股账面**已发生深套（浮亏 $\le -15\%$）**时，系统会启动解套小助手：若所处阶段为 **Accumulation (筑底吸筹)** 或 **Markup (拉升中继)**，系统会将主风控动作柔性覆盖为 **`HOLD`**（提供滚动做T与加仓区间建议），防止用户在底部支撑位盲目割肉；若所处阶段为 **Markdown (下行主跌)** 或 **Distribution (派发区)**，则维持 `EXIT_ALL` 强平警告。
* **自适应波动率 (ATR) 风控模式**：支持一键开启 ATR 风控。开启后，固定比例的止损与止盈参数将动态转化为 ATR 乘数：初始止损价位设为 `Cost - 2.0 * ATR`，移动止盈设定为自高点回落 `3.0 * ATR`，保本目标设为 `Cost + 4.0 * ATR`（激活后保本防护线设为 `Cost + 1.0 * ATR`），使风控边界能够根据市场近期波动率（ATR）自适应缩放。
* **MACD 自适应降级估算**：风控引擎内置了独立的 EMA 和 MACD 指标计算算法。在 Classic 模式或 Standard Wyckoff 模式下（外部未传入 MACD 状态），引擎会自动重构 MACD 曲线，确保“MACD 辅助减仓”规则在所有分析模式中 100% 生效。
* **突破阶段均线滞后优化 (Breakout Phase Lag Calibration)**：对于刚刚从吸筹区间完成突破的个股（如 MSB）， lagging 的 60日/120日均线通常未能及时金叉（需要 20-40 天滞后）。为了修正此问题，算法引入了事件触发确认机制：若最近 20 天内存在 `JAC/UTAD_Failure`、`SOS` 或 `Flag` 突破事件，且股价当前站稳在阻力位之上，阶段即被直接判定为 **`Phase: Markup`**。

## 三、 威科夫量价结构事件 (Wyckoff Events) 清单

在威科夫（Wyckoff）量价分析中，图表上会标注出如下关键的量价行为事件（Events）。这些小球点代表多空趋势的转折点或爆发确认点：

| 事件代码 (Code) | 中文名称 | 多空方向 | 威科夫技术含义 | 算法触发条件 (When it occurs) |
| :--- | :--- | :---: | :--- | :--- |
| **SC** | 卖出高潮 | 🟢 多头 | 恐慌盘无脑砸盘，筹码由散户转移至主力，探底标志。 | 下跌日且股价处于一年内的下半部分（`pricePos < 0.5`）；成交量比率 `volRatio > 2.0 * sensFactor` 且下影线比重 `lowerTailRatio > 40%`（强力拉回）。 |
| **BC** | 买入高潮 | 🔴 空头 | 追高散户失去理智，主力乘机出货，见顶标志。 | 上涨日且股价处于一年内的上半部分（`pricePos > 0.5`）；成交量比率 `volRatio > 2.0 * sensFactor` 且上影线比重 `upperTailRatio > 40%`（冲高回落）。 |
| **AR** | 自动反弹 | 🟢 多头 | 卖压衰竭后，空头回补与买盘介入导致的自然反弹。 | 紧随 `SC` 之后，股价在抛压枯竭下的强力收阳反弹最高位。 |
| **AR_Reaction** | 自动回落 | 🔴 空头 | 买盘衰竭后，股价获利盘回踩或主力压盘的自然回落。 | 紧随 `BC` 之后，股价在多头衰竭下的自然回调低位。 |
| **ST** | 二次测试 | 🟢 多头 | 测试底部抛压是否确实枯竭。 | 价格跌至 `SC` 最低点附近（`close < trSupport + 1.5 * ATR`），且成交量明显萎缩（`volRatio < 1.0`），未破新低并收阳。 |
| **ST_Dist** | 二次测试（派发） | 🔴 空头 | 测试高位买盘意愿和主力出货决心。 | 价格涨至 `BC` 最高点附近（`close > trResistance - 1.5 * ATR`），且成交量和波动率萎缩，未能站稳。 |
| **Spring** | 弹簧效应 | 🟢 多头 | 假摔扫止损洗盘，大资金暗中吸筹。 | 股价跌破吸筹区间支撑线，但下探深度小于 3% 且 20日线非 Markdown 趋势；在跌破后的 1~3 天内迅速收盘在支撑线之上。 |
| **UTAD** | 上轨假突破 | 🔴 空头 | 向上拉高诱多，突破失败重回区间内，出货警告。 | 股价处于一年内的上半部分（`pricePos > 0.35`），盘中突破区间阻力位，但因高位抛压沉重而收阴，收盘价跌回阻力线下方。 |
| **SOS** | 强势信号 | 🟢 多头 | 股价以摧枯拉朽之势放量冲破阻力区，趋势确立。 | 收盘价创 20 日新高，收阳线；且成交量比率 `volRatio > 1.4 * sensFactor`；同时均线系统不能处于明显的空头弱势死叉状态。 |
| **SOW** | 弱势信号 | 🔴 空头 | 股价放量砸穿关键支撑，多头溃败，趋势转空。 | 收盘价创 20 日新低，收阴线；且成交量比率 `volRatio > 1.4 * sensFactor`。 |
| **BU** | 无量回踩确认 | 🟢 多头 | 阻力转支撑确认（回踩发射台），稳健买点。 | 过去 15 天内有放量突破阻力，当前向阻力线回测；低点未跌破 `阻力线 - 1.0 * ATR`，且成交量极度萎缩（`volRatio < 0.85`）并收阳企稳。 |
| **UTAD_Failure** | 空头踩踏突破 | 🟢 多头 | 假突破被多头主力强力吃掉，触发空头止损踩踏。 | 在发生 `UTAD` 假突破后的 20 个交易日内，股价并没有如期下跌，反而强力拉升且收盘价站上该 UTAD 发生当天的最高价。 |
| **Flag** | 黄金旗形突破 | 🟢 多头 | 主升浪中继“空中悬停”蓄势，放量二次起飞，极强买点。 | 处于拉升阶段（`Phase: Markup`，均线多头排列）；前 3~8 天处于窄幅高位缩量横盘整理（振幅 `< 7%` 且平均量 `< 85%`）；今日放量阳线（`volRatio > 1.2`）突破整理高点。 |

## 四、 套牢解套助手专家决策矩阵

当 $\text{当前浮盈Pct} \le -15\%$ 时激活，根据当前的**趋势/威科夫阶段 (Phase)** 提供自适应解套方案：

| 判定阶段 (Phase) | 诊断行为 (Action) | 解套策略指导 (Advice) | 执行价格参考 (Range) |
| :--- | :--- | :--- | :--- |
| **Markdown (主跌浪)** | `EXIT_ALL` (强制清仓) | 均线呈空头排列，下行空间未出尽。强力建议痛斩割肉或换股至 Markup 强势股中。 | *无（不建议补仓摊成本，逢高尽快离场）* |
| **Accumulation (吸筹筑底)** | `HOLD` (防守持股做T) | 价格临近强支撑，不宜盲目割肉。建议底仓滚动做T，利用区间高抛低吸做T摊低成本。 | `支撑位附近低吸` / `阻力位附近高抛` |
| **Distribution (高位派发)** | `EXIT_ALL` (逢反弹清仓) | 主力机构正在出货，虽已套牢但后续暴跌空间巨大。反弹是最后安全退场机会，切勿补仓。 | `阻力位附近（逢高出局）` |
| **Markup/Other (上涨中继)** | `HOLD` (持股逢低加仓) | 处于上涨大趋势的回调，多头尚存。持股等待均线好转或 MACD 重新金叉后右侧加仓。 | `强支撑位附近（右侧加仓）` |

## 五、 UI 界面交互设计说明

### 1. 左侧：风控设置面板 (Risk Control Config)
* **持仓成本输入框**：支持保留两位小数的每股成本。
* **智能提示助手横幅**：输入成本且有股票分析数据时，自动渲染小灯泡提示（例如：“💡 个股特征：中波动成长股（日均波幅 2.3%）... 推荐：移动止盈 15%，保本 30%”），并提供 **`[点击套用]`** 一键对齐滑块。
* **名词解释文案**：在各滑块下方配有淡雅、倾斜的专业名词通俗释义（完美适配中/英文）。

### 2. 右侧：智能风控诊断看板 (Risk Diagnostics Card)
* **动态渐变背景色**：根据推荐决策自动渲染卡片边框与背景梯度：
  * `EXIT_ALL`（清仓）➔ **淡红渐变** 🚨
  * `REDUCE_50`（减仓）➔ **淡橘渐变** ⚠️
  * `HOLD`（继续持有）➔ **雅绿渐变** ✅
* **风控指标栅格**：展示当前盈亏率、自买入后最高点、最高点回撤幅度。
* **触发价格列表**：清晰列出初始硬止损价、移动止盈触发价、保本激活目标价以及保本防护线，并动态反馈“保本锁”的激活状态 (🔒/🔓)。
* **触发依据列表**：列出触发当前减仓/清仓决策的多重技术理由。
* **套牢助手子卡片**：浮亏 $\le -15\%$ 时，会在面板底部弹出专属子卡片，呈现上述解套策略指导及具体的支撑/阻力套做T执行价区间。

## 六、 代码文件结构关系

* [riskControlAnalyzer.js](./src/utils/riskControlAnalyzer.js)
  * **职责**：风控策略与解套策略的纯计算逻辑模块。不依赖 React 或 DOM，专职做数学模型运算和语言文本组装。
* [LiveAnalyzer.jsx](./src/components/LiveAnalyzer.jsx)
  * **职责**：用户界面的状态控制与渲染。在 `useEffect` 中触发 `analyzeRiskControl`，在左侧 sidebar 渲染滑块及一键套用，在右侧结果区域渲染多态看板。
* [wyckoffAnalyzer.js](./src/utils/wyckoffAnalyzer.js)
  * **职责**：在分析结果中计算 Average ATR %，划分波动评级，输出推荐参数 `volatility_metrics`，并返回给 `LiveAnalyzer`。
* [stockAnalyzer.js](./src/utils/stockAnalyzer.js)
  * **职责**：在 Classic 诊断引擎中同步计算 Average ATR % 及推荐矩阵，确保经典分析与 Wyckoff 分析风控指标的一致性。
